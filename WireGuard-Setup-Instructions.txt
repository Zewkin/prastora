КАК ПОДКЛЮЧИТЬСЯ К VPN:
========================================

СПОСОБ 1: Через QR-код (для мобильных устройств)
-------------------------------------------------
1. Установите приложение WireGuard на ваше мобильное устройство:
   - Android: https://play.google.com/store/apps/details?id=com.wireguard.android
   - iOS: https://apps.apple.com/us/app/wireguard/id1441195209

2. Откройте приложение WireGuard

3. Нажмите "+" и выберите "Сканировать QR-код"

4. На сервере выполните команду для отображения QR-кода:
   qrencode -t ansiutf8 < /opt/prastora/wg-client.conf

5. Отсканируйте QR-код камерой

6. Активируйте VPN-подключение


СПОСОБ 2: Через конфигурационный файл (для компьютеров)
--------------------------------------------------------
1. Установите WireGuard на вашем компьютере:
   - Windows: https://www.wireguard.com/install/
   - macOS: brew install wireguard-tools (или из App Store)
   - Linux: sudo apt install wireguard (Debian/Ubuntu)
            sudo dnf install wireguard-tools (Fedora/RHEL)

2. Скачайте конфигурационный файл:
   Файл находится здесь: /opt/prastora/wg-client.conf

3. Импортируйте конфигурацию:
   - Windows/macOS: Откройте приложение WireGuard -> Import tunnel(s) from file
   - Linux: sudo cp wg-client.conf /etc/wireguard/
            sudo wg-quick up wg-client

4. Активируйте VPN-подключение

========================================
УПРАВЛЕНИЕ СЕРВЕРОМ (для администратора):
========================================

Проверить статус WireGuard:
  ssh root@185.235.218.236
  wg show

Перезапустить WireGuard:
  systemctl restart wg-quick@wg0

Остановить WireGuard:
  systemctl stop wg-quick@wg0

Запустить WireGuard:
  systemctl start wg-quick@wg0

Просмотреть логи:
  journalctl -u wg-quick@wg0 -f

Проверить правила iptables:
  iptables -t nat -L -n -v
  iptables -L FORWARD -n -v
